# Скрипты для электронного дневника

Учебный проект для урока Devman по Django ORM.

Скрипт работает с базой данных проекта электронного дневника:
https://github.com/devmanorg/e-diary

Он умеет:

- исправлять двойки и тройки на пятёрки;
- удалять замечания выбранного ученика;
- добавлять случайную похвалу за последний урок указанного предмета.

## Что понадобится

Сначала должен быть установлен и настроен сам электронный дневник, а его база данных должна быть подключена.

Файл `scripts.py` нужно положить рядом с `manage.py` проекта электронного дневника.

## Запуск

Откройте терминал в папке проекта электронного дневника и запустите Django shell:

```bash
python manage.py shell
```

Если на вашей системе используется команда `python3`, запустите:

```bash
python3 manage.py shell
```

В Django shell импортируйте функции:

```python
from scripts import (
    create_commendation,
    fix_marks,
    get_schoolkid,
    remove_chastisements,
)
```

## Исправить оценки

Сначала найдите ученика:

```python
schoolkid = get_schoolkid('Фролов Иван')
```

Затем исправьте двойки и тройки на пятёрки:

```python
fix_marks(schoolkid)
```

## Удалить замечания

Используйте уже найденного ученика:

```python
remove_chastisements(schoolkid)
```

## Добавить похвалу

Укажите имя ученика и название предмета:

```python
create_commendation('Фролов Иван', 'Музыка')
```

Похвала будет создана для последнего найденного урока этого предмета. Текст похвалы выбирается случайно.

## Другой ученик

Для другого ученика достаточно изменить имя:

```python
schoolkid = get_schoolkid('Голубев Феофан')
fix_marks(schoolkid)
remove_chastisements(schoolkid)
create_commendation('Голубев Феофан', 'Математика')
```

## Проверка ошибок

Если имя не найдено:

```python
get_schoolkid('John')
```

Скрипт сообщит, что ученик не найден.

Если запрос подходит сразу нескольким ученикам:

```python
get_schoolkid('Степан')
```

Скрипт сообщит, что найдено несколько учеников и попросит уточнить имя.

Если предмет указан с ошибкой или уроков по нему нет:

```python
create_commendation('Фролов Иван', 'матиматика')
```

Скрипт сообщит, что уроки по такому предмету не найдены.

## Важно

Скрипт изменяет данные в базе. Перед экспериментами полезно сохранить резервную копию файла базы данных.

Репозиторий содержит только скрипт для работы с уже настроенным электронным дневником. Код самого Django-сайта и база данных сюда не входят.
